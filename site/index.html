why it doesn't exist yet

Two problems were solved. Nobody joined them.

Tools that keep an agent running

  • Ralph loops, Anthropic's ralph plugin
  • rate-limit resumers, overnight runners
…but they re-send one canned string.

Tools that learn from your history

  • chat memory, "write like me" cloners
  • transcript miners, style profiles
…but they only clone what the agent says back.

Ghost Type is the first to write the next thing you'd type — after 181 tools swept, still nobody else does.

a night, in six moves

You give it a goal. It does the loop.

01

Clone

A throwaway local clone of the repo. Its origin remote is deleted — push is impossible.

02

Work

A fresh claude session in the clone, scoped tools only, your other API keys stripped out.

03

Watch

Done, stalled, rate-limited, or offline — four states, never confused for one another.

04

Verify

Ghost Type runs the test itself. A "done" that didn't pass is caught as a false-done.

05

Write

The next prompt, in your voice, from the real trace. Three strikes on one bug and it parks it.

06

Report

Reviewable branches and a morning notification — a good night, or a bad one, is never silent.

You leave. It keeps working — in an isolated clone that can never touch your real checkout.
safe by construction, not by promise

Four things that could go wrong at 3am. They can't.

it wrecks your repo
Works in an isolated clone — your real working tree is never opened.
it pushes junk while you sleep
The clone's origin is deleted. Push has nowhere to go.
it burns your other API credits
Non-Claude keys stripped from the session by default.
it runs forever / a huge bill
Budget cap + token cap + a hard 07:00 stop.
it sounds like you

Not a generic assistant. You, at 2am.

Ghost Type learns from your own session history — how you kick things off, how you redirect after a failure, how you demand proof. The prompts it writes read like yours, and every one lands in the morning report for you to grade.
